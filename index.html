同一个 MLP，两种常见工作流

能力并没有硬边界：TensorFlow 也能手写训练循环，PyTorch 也能进一步封装。这里比较的是初学与日常项目中最常见的写法。

PyTorch · 显式训练循环

每一步都摆在眼前，适合理解与调试

容易观察每一步
1optimizer.zero_grad() # 清除旧梯度
2hidden = torch.sigmoid(x @ W + b)
logits = hidden @ v + c
3loss = F.binary_cross_entropy_with_logits(logits, target)
4loss.backward() # 梯度写入 .grad
5optimizer.step() # 更新参数
你能直接停在任一步：查看张量形状、`loss`、每个参数的 `.grad`，或替换其中一个计算环节。

TensorFlow / Keras · 标准流程

把常规训练交给框架，快速得到模型

快速完成标准模型
1model = keras.Sequential([
  layers.Dense(2, activation="sigmoid"),
  layers.Dense(1)
])
2model.compile(optimizer="adam", loss=...)
3model.fit(x, target, epochs=300)
框架代办常规步骤：前向传播、梯度计算、参数更新、批次循环和训练日志都由 `fit` 统一组织。
PyTorch 常见风格更显式 · 更便于逐步观察
TensorFlow/Keras 常见风格更封装 · 更快搭建标准模型
