# XOR MLP 参数学习实验室

一个无依赖、单文件的静态交互网站，用来解释 2→2→1 MLP 如何通过 Adam 学会 XOR。

## 本地打开

直接双击 `index.html`，或在目录中启动任意静态服务器。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库并上传 `index.html` 与 `README.md`。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/ (root)`，保存即可。

网站没有后端、依赖或构建步骤。
